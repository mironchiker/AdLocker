# 🛡️ AdLocker Engine

> **AdLocker** — легковесный локальный блокировщик рекламы и трекеров для Android без root-прав, созданный на связке Flutter и нативного Kotlin VpnService.

## ⚡ Особенности

* **Локальный Sinkhole (0.0.0.0):** рекламные домены и аналитика глушатся прямо на устройстве без отправки лишних пакетов в сеть, экономя трафик и батарею.
* **База на 260 000+ правил:** надёжно блокирует рекламу в приложениях и играх (включая Unity Ads).
* **Умный апстрим:**
  * Основной: `xbox-dns.ru` (для быстрого отклика и доступности игровых сервисов).
  * Резервный: `AdGuard DNS` (дополнительная защита и фильтрация при сбоях).
* **Белый список на лету:** возможность добавлять исключения без перезапуска службы.
* **Автоматизация CI/CD:** правила автоматически обновляются по расписанию через GitHub Actions.
* **Минимальное потребление памяти:** оптимизированная построчная обработка списков правил без утечек RAM.

---

## 🛠️ Стек технологий

* **Frontend:** [Flutter](https://flutter.dev/) (Dart) — чистый тёмный интерфейс со статистикой запросов.
* **Backend / System:** Kotlin (`VpnService`, сокеты) — перехват и маршрутизация DNS-трафика.
* **Inter-op:** `MethodChannel` для быстрой связи между UI и фоновым сервисом.
* **CI/CD:** GitHub Actions (автоматическая сборка APK и обновление `rules.txt`).

## 📥 Установка

1. Перейдите во вкладку [Releases](mironchiker/AdLocker/releases).
2. Скачайте свежий файл `AdLocker.apk`.
3. Установите на Android-устройство и разрешите создание VPN-подключения при первом запуске.
